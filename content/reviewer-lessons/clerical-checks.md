# Use two passes for names and identifiers

Draft editorial supplement. Original, unreviewed teaching material with proposed solutions. The filing rules here are explicitly stated exercise rules, not universal rules for every office.

## Learning objectives

- Apply the stated filing key in the correct order.
- Distinguish a comparison used for ordering from an exact transcription.
- Check leading zeroes and similar-looking letters or digits.

## Explanation

Use one pass to identify the required rule and a second pass to compare details. If the instruction says surname first and given name second, a given name must not override an earlier surname difference. When surnames match, compare the given names from left to right.

Transcription is a separate task. You may interpret a numeric suffix for sorting while still preserving its original characters when copying the identifier. Leading zeroes, punctuation and letter case can matter in an exact-copy exercise.

## Worked example

### Example 1: Compare at the first different letter

Sort these names by surname, then given name, using ordinary English alphabetical order without case differences: Alba, Nora; Alba, Neri; Alba, Nilo.

1. Every surname is Alba, so the second key decides the order.
2. Every given name starts with N.
3. Their next letters are o, e and i.
4. Since e comes before i and i before o, the answer is **Alba, Neri; Alba, Nilo; Alba, Nora**.

Do not sort by the final letter or the length of the name; those are not the stated keys.

### Example 2: Copy an identifier exactly

The source identifier is **KQ-0074-LZ**. Two proposed copies are KQ-0074-L2 and KQ-0074-LZ. Which matches?

1. Compare the prefix KQ and the hyphens.
2. Check that the numeric block contains both leading zeroes: 0074.
3. Compare the final two characters: L followed by the letter Z.
4. The exact match is **KQ-0074-LZ**. The other copy substitutes the digit 2 for Z.

Reading the source aloud in groups can help locate the difference, but the final check must compare the written characters.

## Practice

The stated rule is: identical alphabetic prefixes first, then sort the suffix as an ordinary positive integer. Order P-9, P-12 and P-3. Preserve each identifier exactly as supplied in the final list.

Write the suffix values separately for comparison, then copy the original full identifiers into the chosen order.

## Rationale

The suffix values are 9, 12 and 3. Their ascending numerical order is 3, 9, 12, so the proposed answer is **P-3, P-9, P-12**. P-12 would come before P-3 under a different character-by-character comparison, but that is not the rule stated here. Do not change the output to P-03 or P-09, because exact source identifiers must be preserved.

## Common mistake

Do not assume that one office's filing convention applies to a different exercise. Read the given rule first, then compare every character needed by that rule.
