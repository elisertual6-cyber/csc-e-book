# Practise a method, then examine the evidence

Draft editorial sample · Common track · Version 0.1

This original, ungraded teaching draft awaits independent correctness, originality, source and language review. It is not an official CSC lesson or a claim of verified 2027 coverage. Build a repeatable routine using retrieval, explanation and an error log.

## Learning objectives

- Break a broad topic into a small, observable practice goal.
- Separate a correct answer from a well-supported solution method.
- Use an error log to choose the next review task.

## Explanation

A useful session has a question, an attempt, feedback and a follow-up. Start with a small goal such as comparing percentages with different bases. Attempt a few items without consulting the explanation. Then check the key, reconstruct the reasoning and note why a distractor was tempting. Reading a solution is different from being able to produce it independently.

Classify an error before adding more questions. A knowledge gap calls for a lesson or worked example. A modelling error calls for identifying quantities and relationships. A transcription error calls for a deliberate copying check. A timing problem may require a smaller timed practice after the method is reliable. One mistake can have more than one cause.

Return to earlier material after an interval and mix a few related skills. These are study suggestions, not a guaranteed passing formula or an official examination timetable. Difficulty labels and question counts describe this draft resource only. Use current official CSC announcements separately for eligibility, coverage and schedules.

## Worked example

A learner answers “20%” when attendance rises from 64 to 80. The increase is 16, but the correct comparison base is the original 64: 16/64 = 25%. The error log can say: “I used the final value as the denominator. Next time, underline the reference base before calculating.” This identifies a repairable method error rather than merely recording a wrong letter.

## Practice

1. Write one observable goal for a 20-minute session on fractions.
2. A learner guessed correctly but cannot explain the chosen denominator. Should the item be considered mastered? Why?
3. Record a follow-up task for a repeated digit-transposition error.

## Rationale

For item 1, a suitable goal is “convert and compare four fractions with unlike denominators, showing the common denominator.” For item 2, a correct guess alone does not demonstrate the method; solve a fresh example and explain it. For item 3, compare the copy with the source character by character, then repeat with a different identifier.
