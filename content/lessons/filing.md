# Apply the stated filing rule consistently

Draft editorial sample · Subprofessional track · Version 0.1

This original teaching draft awaits independent correctness, originality and language review. The conventions below are declared exercise rules, not official government records-management standards. Actual filing policies can differ.

## Learning objectives

- Compare filing keys character by character using an explicit rule.
- Distinguish alphabetical ordering from numerical identifier ordering.
- Preserve names and identifiers when checking an ordered list.

## Explanation

Read the filing rule before comparing records. An organization may specify how to handle surnames, prefixes, punctuation, spaces and numbers. Never assume that every institution uses one convention. For the alphabet exercises here, compare the supplied uppercase A–Z keys exactly as written, from left to right. If one key is an exact prefix of another, the shorter key comes first. Questions using this rule contain no spaces, punctuation or accented letters.

Compare the first position where two keys differ. Earlier matching letters do not decide the result. For example, ABEL comes before ABLE because their third letters are E and L. A short key is not automatically earlier than an unrelated longer key; length breaks the tie only when it is an exact prefix.

For a separate numerical exercise, suppose all identifiers share the same letter prefix and the rule says to order the suffix by numerical value. Then F-2 precedes F-10. Comparing the suffixes as text would produce a different result. Leading zeros must also be addressed by the policy: they may be formatting or part of a distinct identifier. This lesson does not erase or silently reinterpret them.

Accuracy requires more than ordering. A correctly placed record can still contain a transposed digit. Check the complete displayed identifier against its source and preserve the original characters in the record.

## Worked example

Sort the keys **ALTO, AL, ALBA** under the declared uppercase comparison rule.

The order is **AL, ALBA, ALTO**. AL is an exact prefix of the other two keys, so it comes first. ALBA and ALTO first differ at the third position: B comes before T. The decision follows the declared comparison rule, not assumptions about whether a key is a person's actual name.

## Practice

1. Under the same alphabet rule, which comes first: ABEL or ABLE? Identify the deciding position.
2. Under numerical-suffix ordering, arrange F-12, F-3 and F-8.
3. Compare the source ID R-4726 with the copy R-4762. Is the copy exact?

## Rationale

For item 1, ABEL comes first at the third position. Item 2 is F-3, F-8, F-12 because 3 is less than 8, which is less than 12. Item 3 is not exact: the final two digits are transposed. Correct ordering cannot repair that copying error.

## Reflection

Explain the comparison rule before applying it. Independent review should test ties, prefixes and numerical treatment, and reject questions that depend on an unstated filing policy.
