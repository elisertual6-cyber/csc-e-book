# Five sequential 160-question practice sets

The series contains **five sets of 160 questions (800 total)**, each with four choices, one proposed answer and an explanation. Set 1 reuses the existing `practice160-` collection; Sets 2–5 add **640 new questions** under `series2-` through `series5-`. The preceding 70 editorial questions and one-question demo seed are outside this series. Overall source totals are 23 lesson drafts, 870 editorial questions in 14 packs, and 871 records including the seed. No draft is automatically reviewed or published. The operator subsequently requested activation of all five sets without their review; the dedicated release now permits these free sets as explicitly labelled **Unreviewed practice**, while preserving their editorial statuses.

Each set includes eight items in each of 20 topics: arithmetic, fractions, ratios, sequences, word problems, data, vocabulary, grammar, sentences, paragraphs, reading, Filipino, analogies, logic, filing, spelling, Constitution, ethics, rights and environment. This is mixed Professional/Subprofessional skill practice, with COMMON series metadata; it is not an official CSC mock blueprint, timing or scope claim.

## Learner behavior

Open `/practice/sets`, also linked from the practice studio and account page. Sign in to see all five set cards and account-owned progress. Each released set is free, untimed, contains exactly its fixed 160 members and saves answers online. Learners may leave and resume. A labelled Question number selector makes all 160 items accessible without a wall of navigation buttons.

Answer all 160 questions and submit to complete a set. No minimum score is required: completing a set with zero correct answers still unlocks the next released set. Skipping a set, changing its count/topic or submitting a partial set is rejected on the server. Proposed answer keys and explanations appear only after submission. Unreviewed releases display a clear warning on the set cards and inside the attempt, including its results. Completed results remain in private history, and learners can practise a completed set again. Retrying a completed set does not remove previous completion.

Completion comes from immutable, fully answered, submitted attempts belonging to the signed-in account, never localStorage, client scores or browser flags. All earlier sets must be completed. The existing ownership, private caching, Origin/action-header checks, immutable snapshots, revision/save locks and start/submit idempotency remain. Concurrent starts for the same unfinished set return one active attempt. The normal three-active-session cap still applies to new attempts. Ordinary topic practice and timed mocks retain their original behavior, including partial submissions; fixed sets are not mixed into the generic template lobby.

## Explicit unreviewed-practice release

The user explicitly requested activation of all five sets without their review. `npm run practice:activate-unreviewed -- --apply` performs that scoped release under a current ADMIN. It validates the exact five fixed configurations and all 800 complete question versions before changing anything; an invalid/missing/archived item rolls back the whole activation. It creates no Review rows and changes no Question status.

Each template receives a `practice-series.activate-unreviewed` audit event containing the authorized question IDs, keys, versions and content hashes. New attempts may use those precise non-archived versions even while they are DRAFT; editing that content blocks new attempts until an explicit new release records the changed version/hash. New unaudited drafts cannot silently replace the pinned version. Reviewed PUBLISHED versions remain eligible through the usual independent-review checks. Repeating the release preserves active template versions and does not duplicate unchanged authorizations. Existing attempts retain immutable content and unreviewed labels.

The workflow starts on main pushes changing the explicit release-intent file, and also supports manual dispatch. It shares the existing database-operation concurrency group. A Git push is not evidence that the hosted job succeeded: inspect the workflow result and all five active templates. After activation, only Set 1 is immediately startable for a new learner; Sets 2–5 remain sequentially locked until predecessors are fully answered and submitted. No new migration or environment variable is needed.
