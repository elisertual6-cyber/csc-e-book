# Phase 5K — five sequential 160-question practice sets

The user requested at least five 160-item sets with answer keys and access to each next set after finishing the preceding one, informed by online CSC-related reviewers and publications. Delivered five fixed sets, 800 distinct keyed prompts with four choices and a proposed key/rationale per item. Set 1 reuses the prior 160; Sets 2–5 add 640. Each set covers 20 topics with eight items per topic. Overall totals become 23 lesson drafts, 870 editorial questions across 14 packs and one separate seed (871 combined records). All actual source material remains DRAFT.

Online research actually consulted public community CSC reviewer examples/category documentation and OpenStax publisher textbook concepts through accessible GitHub sources. Provenance URLs, relevant document hashes and licensing limitations are recorded in `content/references/practice-series-sources.json` and item notes. New item wording, scenarios, options and explanations are original; source question banks and textbook passages/exercises/images are not reproduced. Ambiguous community keys are not adopted as authority. Direct primary CSC/Lawphil/UN retrieval was blocked, so official coverage, current primary text/legal applicability and qualified Filipino checking remain pending. These are mixed-track educational exercises, not official 2027 examination papers or a verified mock blueprint.

The additive migration extends ExamTemplate with nullable series identity/position and fixed question-key membership, a unique position and shape constraints. Existing templates/attempts/content are preserved. The SQL expansion was pushed separately at `9b93530` for migration before deploying the new Prisma/runtime code. Existing private table policies remain. No new tables, payments, registration, provider or email behavior are introduced.

`/practice/sets` provides five account-owned cards, saved/resumable attempts, an accessible question-number selector, complete-submission gating and sequential unlocks. Completion requires all 160 saved valid answers in a submitted own attempt with matching series metadata. Any score qualifies. Direct start APIs enforce all predecessors; partial/count/topic overrides and browser completion flags cannot bypass the sequence. Concurrent same-set starts deduplicate; submissions remain idempotent and snapshots immutable. Pre-submission DTOs contain no keys/rationales/correctness flags. Existing ordinary topic/mock selection, timers, partial submission, ownership, entitlement checks and focus/save locks remain intact.

The admin Question collection selector loads the latest version of each fixed key and reports actual imported counts out of 160, avoiding the legacy unfiltered 200-record display limit. Fixed template membership cannot be changed through normal saving. Activation/deactivation remains explicit, with independent approval/PUBLISHED eligibility rechecked for all members before activation and each new start. Inactive/unprepared sets have truthful availability states.

A main-only manual import workflow checks the schema and imports ten fixed 80-item packs, preserving existing edits/versions/lifecycle and pack-level rollback/repeat safety. A separate current-ADMIN preparation transaction creates five inactive FREE untimed templates; conflicts preserve existing records. Actual source import tests create no reviews, publications or activation. Synthetic browser fixtures use clearly invented content in generated databases to exercise reviewed states; those approvals do not apply to the actual 800 questions.

Operator exports derive five numbered booklets and five proposed keys from the same manifests. Network-disabled Chromium produced ten PDF review documents: each question booklet is 41 pages; Set 1's key is 24 pages and Sets 2–5 keys are 23 pages each. Every PDF was checked by text extraction for all 160 numbered headings, and every CSV has 160 entries. Set 2 question/key first pages were visually inspected. The ZIP includes PDF/Markdown/CSV copies, source provenance and an explanatory readme. These are local review documents, not application editions or released storage objects.

## Rollout boundary

Hosted migration success, deployment, draft import, actual independent review, template activation and real learner behavior remain operator verification steps. The local environment cannot confirm the hosted migration through its restricted GitHub API access. The new runtime must not deploy before that migration succeeds; code can be kept on a feature branch pending confirmation. See [PRACTICE_SERIES.md](PRACTICE_SERIES.md). No actual question is auto-approved to satisfy a release target, and no test result is described as official CSC verification.
