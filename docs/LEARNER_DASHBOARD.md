# Focused learner dashboard

`/account` keeps the existing sign-in and current-user checks and becomes the learner's home. The dashboard shows one primary next action, three compact recent-result/set metrics, a single course-progress bar, the latest completed result and one subject suggestion. Marketing announcements are hidden on this page. Account settings, sign-out, staff tools and orders remain available in a labelled native disclosure, collapsed initially. No payments or registration settings are enabled.

The next action resumes an accessible active attempt, prioritizing the earliest running deadline. Otherwise it links to the learner's next available/in-progress practice set, or to the practice studio. It never starts a session automatically or changes sequential unlocks. The timer continues while away; the existing attempt service remains authoritative.

Dashboard data comes only from the existing authenticated `/api/exams/history` and `/api/exams/series` summaries. No question content, private grading snapshot or correct-answer keys are fetched for the dashboard. Current access checks on attempt reads/writes remain mandatory; locked premium attempts do not receive resume/review links. Recent metrics cover the existing latest-50 history window, not lifetime totals. Set completion remains server-owned and separate. A failed section shows an unavailable value and retry control while preserving the other section, rather than fabricating a zero.

The suggested subject is the lowest recent correct/total ratio with missed or unanswered items; equal ratios prefer the larger sample. Destinations come from the fixed public reviewer catalog and known chapter anchors, with the public library as fallback. This is a simple study suggestion, not an official score, diagnostic assessment or readiness prediction. No profile is sent to an external service, and private data is not put in browser storage or URLs.

Use the disposable browser wrapper. The dashboard tests cover first-use emptiness, next-action resume, actual result metrics, owner isolation, reviewer navigation, collapsed/expanded account tools, section failure/retry, responsive layout and automated accessibility. Existing authentication tests now open the account-tools disclosure before signing out. See EXAM_OPERATIONS.md for results filtering and REVIEWERS.md for the six added teaching chapters.
