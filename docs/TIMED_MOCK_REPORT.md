# Timed mock availability fix

The visible Session type option had no corresponding released database template. The existing clock engine was implemented, but users could not start a timed session. Added two specifically authorized free draft mocks for Professional and Subprofessional, each using 160 existing track-matched questions and a 150-minute practice timer. The five sequential untimed sets are unchanged.

The release CLI and main-only workflow create only those exact configurations and pin question versions/content hashes in audit events. They validate both sessions before committing, preserve question status/review rows, reject conflicting existing configurations and are idempotent. Other mocks/topics and commercial releases retain independent-review checks. The lobby and immutable attempt metadata identify unreviewed material; keys remain withheld before grading. The player uses compact question-number navigation for large sessions and the existing database deadline/acknowledged-save logic.

Local evidence: lint, TypeScript, 123 unit tests, content validation (23 public drafts, 871 editorial/seed records), production build (52 verified trace manifests) and local database integration passed. Dedicated desktop/mobile timed-mock browser tests passed, including atomic release failure, current admin requirement, track exclusions, no fabricated approvals, fixed count/timer, countdown movement, reload persistence, account isolation, expiry, rejected late saves, immutable snapshots and draft/configuration invalidation. Axe scans passed on the selected lobby and active 160-item player on both viewports. Additional regression results and hosted release evidence are recorded after completion below.

These are local automated checks, not independent content review, official CSC blueprint verification, manual accessibility conformance or production capacity evidence. See [TIMED_MOCKS.md](TIMED_MOCKS.md) for release and learner instructions.

Regression results: all 35 general browser checks, all four sequential-series checks and all four authenticated accessibility workflows passed through disposable database wrappers. The keyboard-navigation test was updated for the renamed sign-in link. The dedicated timed-mock suite passed both desktop and mobile again after the release logic was finalized. Hosted activation is not inferred from these local results.
